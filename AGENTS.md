# Инструкции для агентов

## Карта проекта

- `Open Studio.bat` и `Open Studio.ps1` — запуск локальной Studio.
- `clip/clip_service/` — основной Python-код API, обработки видео, Studio и озвучки.
- `clip/clip_service/studio_web/` — веб-интерфейс Studio и его статические файлы.
- `clip/gaming-run.db` — рабочая SQLite-база. Не удалять и не заменять тестовой базой.
- `clip/gaming-run-storage/` — рабочие исходники, клипы, экспорты, проекты CutWright и озвучки.
- `clip/models/` — локальные модели, включая Piper для озвучки.
- `clip/tools/ffmpeg/` — локальный FFmpeg, используемый запуском Studio.
- `clip/.venv/` — Python-окружение. Оно локальное и не должно попадать в архивы или коммиты.
- `clip/tests/` — тесты проекта.
- `клипы/Parabolic/` — отдельное приложение Parabolic и его данные; не смешивать с кодом Clip Service.
- `storage/` — отдельные материалы storyboard, не путать с рабочим `clip/gaming-run-storage/`.
- `audit/` — результаты проверок, скриншоты и отчёты; это не рабочее хранилище Studio.
- `трансфер/` — копия комплекта для передачи другому человеку.

## Запуск

Из корня проекта запускайте `Open Studio.bat`. Он использует `clip/.venv`, базу
`clip/gaming-run.db`, storage `clip/gaming-run-storage` и локальный FFmpeg.

Для Python-команд переходите в `clip` и используйте:

```powershell
.\.venv\Scripts\python.exe
```

## Правила изменений

- Перед изменениями остановите Studio и сохраните резервную копию рабочей базы.
- Не удаляйте рабочую базу, `clip/gaming-run-storage`, модели, исходные медиа или проекты без явного указания.
- Тестовые базы и временные storage создавайте с отдельными именами, не рядом с рабочими данными.
- Не передавайте и не коммитьте `.env`, API-ключи, токены и другие секреты.
- При изменении схемы базы используйте миграцию в `clip/clip_service/db.py`, чтобы старые рабочие базы открывались.
- После изменений Python запускайте `python -m pytest -q` из `clip`.
- Изменения интерфейса проверяйте через `/studio/` и сохраняйте проверочные материалы только в `audit/results/`.

## Передача комплекта

Для передачи используйте содержимое `трансфер/`. В нём уже есть отдельные инструкции,
рабочая база, storage, код, FFmpeg, модели и Parabolic. Секретный `.env` туда не копируется.
